# OS-Command-Injection-Labs-PortSwigger-Web-Security-Academy
Documentation of OS Command Injection labs completed during hands-on web application security training. Covers command injection identification, blind exploitation techniques, output redirection, time delays, and out-of-band interactions using industry-standard methodologies.
Labs Covered
OS Command Injection – Simple Case
Blind OS Command Injection with Time Delays
Blind OS Command Injection with Output Redirection
Blind OS Command Injection using Out-of-Band (OAST) Techniques
Skills Developed
Identifying OS Command Injection vulnerabilities
Understanding shell metacharacters and command separators
Detecting blind command injection through observable side effects
Leveraging time-based techniques to verify command execution
Understanding output redirection mechanisms
Learning Out-of-Band Application Security Testing (OAST) concepts
Analyzing application behavior to identify security weaknesses
Strengthening web application penetration testing methodology
Key Takeaways

These labs reinforced the importance of secure input handling and demonstrated how user-controlled input can impact server-side command execution when appropriate security controls are not implemented.

In addition to learning how command injection vulnerabilities are discovered, I gained practical experience understanding how attackers may validate command execution even when applications do not directly expose command output.
